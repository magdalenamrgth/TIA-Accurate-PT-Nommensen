## 📄 Ringkasan Tugas
Repositori ini berisi laporan tugas mengenai penerapan Sistem Informasi Akuntansi terkomputerisasi menggunakan perangkat lunak **Accurate 5 Education**. 

Ruang lingkup pembahasan mencakup:
1. Pembuatan database perusahaan baru (*PT. NOMMENSEN*).
2. Persiapan singkat & impor data master (*Chart of Accounts*, Data Pelanggan, Data Pemasok) via file Excel.
3. Pencatatan transaksi operasional bisnis.
4. Penyusunan dan pencetakan Laporan Keuangan otomatis.
